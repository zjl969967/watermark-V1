# 06 · 评估规范

## 1. 指标定义

| 指标 | 定义 | 目标 |
|------|------|------|
| 消息准确率 | 18 bit 整串完全正确的图像比例 | 屏摄后越高越好（PIMoG 口径类似：30 bit 位准确率） |
| 消息位准确率 | 18 bit 逐位正确率 | 诊断用 |
| 序列 BER | 192 符号硬阈值后逐位误码率 | 诊断用，训练时快速反映提取质量 |
| PSNR | 含水印图 vs 原图 | 不可见性（参考 PIMoG 通常 > 30 dB） |
| 统计偏差 | 提取序列 6 特征 vs 目标网格值 | 诊断用（应 < 相邻网格间距的一半） |

## 2. 端到端测试流程（真实屏摄）

1. `embed` 生成含水印图；
2. 屏幕放大显示并拍摄（参考 PIMoG README：含水印图占屏幕 ≥ 1/4）；
3. 用 PIMoG 的 `PerspectiveTransformation/*.m` 做透视校正（v1 复用参考项目脚本）；
4. `extract` 校正后的拍摄图，输出消息与准确率；
5. 裁剪测试：对含水印图（或拍摄图）裁剪 20%~80% 后再提取，验证统计层容错。

## 3. 训练期验证

- 每 epoch 在 val 集（含屏摄噪声，`--crop` 时含裁剪）上评估消息准确率 + 序列 BER
  + **PSNR**（含水印图 vs 原图，[−1,1] 值域 10·log10(4/MSE)）；
- 日志同时记录四项损失分量（msg/img/gan/stat），用于判断收敛方向。

## 4. 冒烟测试验收标准（`smoke_test.py`，不依赖外部数据）

| 阶段 | 内容 | 通过标准 |
|------|------|----------|
| S1 编码往返 | 1000 个随机消息构造→解码（含全0/全1） | 消息零错误 |
| S2 特征网格 | 每特征遍历 8 级别，测量 vs 网格表 | F1~F5 精确（≤1e-6）；F6 偏差 ≤ 0.15 |
| S3 容错 | 构造序列随机翻转 1~2 符号再解码 | 消息位准确率 ≥ 16/18 |
| S4 前向形状 | Encoder→Noise→[Crop]→Decoder，batch=2，128×128 | 形状 (2,3,128,128)/(2,192)；无异常 |
| S5 短训练 | 合成数据 32 图，短训练（默认 2 epoch × 4 iter，`--smoke_iters` 可调），全损失（含 GAN） | 损失均为有限值；msg/img/stat 损失不爆炸（≤ 初值×10） |
| S6 端到端 | 训练后 embed 2 图 → ScreenShooting 噪声 → extract | 管线跑通，输出 18 bit 消息（准确率仅作记录，不作门槛） |

全部通过则打印 `SMOKE TEST PASSED` 并退出码 0；任一失败打印阶段与详情，退出码 1。

## 5. 已知限制与扩展（v1 明确不做）

1. **被裁剪位置的处理**：v1 对提取序列全 192 位直接算统计（受损位输出被一并计入）。
   裁剪面积增大时统计量被"稀释"（02 文档 §6 的设计），v1 训练 `--crop` 让解码器学会在
   幸存区域输出正确比特、受损区域输出趋近 0（对 MSE 而言均值最优），从而部分缓解稀释。
   扩展方向：用 PIMoG 式梯度掩膜输出逐位置信度，只统计高置信度位。
2. **单符号翻转的级别敏感性**：N=32、M=8 下 F1~F5 的 −1 翻转恰落在网格中点（02 文档
   §6 边界敏感性说明），F6 单翻转移动 2/31≈0.065 > 半格 0.0625——两者都可能在序列级
   少量误码时引起 1 个级别（≤3 bit）误差。统计层对**裁剪缺失**（无偏子采样）稳健，
   对**随机翻转**仅部分稳健；提高 N（如 64/块，L=384）可彻底解决，作为后续版本选项。
3. 统计层硬阈值 → 可学习的软量化（温度退火）作为后续研究点。
4. 真实数据集上的全量训练与调参由用户执行（D7）。
