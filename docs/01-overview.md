# 01 · 项目概述（STATISTICS）

> 规范文档总入口。本目录（`docs/`）是项目的唯一事实来源（SSD：Spec-Driven Development），
> 所有代码实现必须与本文档体系一致；若实现与文档冲突，以文档为准并同步修订文档。

## 1. 项目目标

设计并实现一种**抗屏幕拍摄（含部分拍摄/裁剪）的鲁棒图像水印**方案。核心思想来自
`statistics.txt`：

- 传统水印在特定位置修改像素，解码依赖定位，图像被裁剪后定位失效 → 水印丢失；
- 本方案把**消息编码在水印序列的统计特征**上：嵌入端构造一条满足目标统计量的水印序列
  并随机嵌入图像；提取端先从图像中提取该序列，再计算其统计量、量化还原比特。
- 由于每个特征块的符号随机散布在全图，裁剪后幸存的符号是全体符号的无偏子样本，
  其统计量仍逼近全体统计量 → **天然抗裁剪**；
- 屏摄鲁棒性由 PIMoG 的可微分屏摄噪声层在训练中提供。

## 2. 关键决策记录（与用户确认）

| # | 决策点 | 结论 |
|---|--------|------|
| D1 | 训练数据 | 项目内建**空目录 `dataset/`**，由用户自行拷贝数据；冒烟测试使用脚本生成的合成数据（`smoke_data/`） |
| D2 | 统计特征 | K=6：正负比例 F1、均值 F2、方差 F3、偏度 F4、峰度 F5、梯度能量 F6 |
| D3 | 容量 | 每特征 M=8 级量化（3 bit），总容量 K×log₂M = **18 bit** |
| D4 | 编码口径 | 统计特征编码在**水印序列**上（非含水印图像上）：消息 → 目标统计量 → 构造满足统计量的 ±1 序列 → 随机嵌入 → 提取序列 → 计算统计量 → 量化还原 |
| D5 | 序列构造 | **分块二值 ±1 序列**：L = 192 = 6 块 × 32 符号；每块用一种特征函数反解参数生成（详见 `02-coding-spec.md`） |
| D6 | 裁剪增强 | 训练默认**仅用 PIMoG 屏摄噪声层**；命令行加 `--crop` 时启用随机裁剪（20%~100% 面积、缩放回原尺寸） |
| D7 | 交付范围 | **实现全部代码 + 合成数据冒烟测试通过**；全量训练由用户自行执行 |

## 3. 与 PIMoG 参考项目的关系

参考项目：`../PIMoG-An-Effective-Screen-shooting-Noise-Layer-Simulation-for-Deep-Learning-Based-Watermarking-Netw-main/`

| 组件 | 复用策略 |
|------|----------|
| 编码器 U-Net（`U_Net_Encoder_Diffusion`） | 复用结构，消息长度 30→192，消息取值 {0,1}→{±1} |
| 解码器 ResNet（`Decoder`/`Extractor`） | 复用结构，输出长度 30→192 |
| 判别器（`Discriminator`） | 原样复用 |
| 屏摄噪声层（`ScreenShooting`：透视+光照+摩尔纹+高斯） | 原样移植 |
| 梯度掩膜引导图像损失（`solver.train_mask`） | 复用思想，去掉 v_mask 通道（本方案数据无掩膜图） |
| 数据加载（COCOMask 双列图） | 不适用，改为普通图像目录（见 `05-dataset-spec.md`） |

## 4. 术语表

| 术语 | 含义 |
|------|------|
| 消息 message | 待传输的 18 bit 二进制串（6 组 × 3 bit） |
| 块 block | 序列中连续 32 个符号构成的一个特征承载单元，共 6 块 |
| 级别 level ℓ | 每特征 8 个量化级别之一，ℓ∈{0..7}，对应 3 bit |
| 网格 grid | 每特征在构造参数空间（p 或 q）上的 8 个离散取值 |
| 水印序列 sequence | 长度 192 的 ±1 序列，编码器实际嵌入的对象 |
| 提取序列 decoded | 解码器输出的 192 维实值向量 |
| 屏摄噪声层 | 可微分的屏幕拍摄模拟（透视/光照/摩尔纹/高斯） |
| 裁剪层 crop | 可微分的随机裁剪+缩放，由 `--crop` 启用 |
| 冒烟测试 smoke test | 不依赖外部数据集的端到端管线验证（`06-evaluation-spec.md` §4） |

## 6. 范围与非目标

**范围内**：上述全部代码、单元测试、冒烟测试、规范文档。

**非目标（v1 明确不做，列为扩展）**：
- 真实屏摄采集、透视校正流程自动化（用户可参考 PIMoG 的 `PerspectiveTransformation/*.m`）；
- 统计层对"被裁剪位置输出"的自适应抑制（如置信度加权统计，见 `06-evaluation-spec.md` §5）；
- 连续实值序列构造（D5 已选二值分块方案）；
- 多尺度（v1 支持 128/256 输入，默认 256×256，`--image_size` 可调）。
